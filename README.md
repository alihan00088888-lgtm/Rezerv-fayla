# RESERV — обновлённый интерфейс

Готовая версия для размещения на GitHub Pages.

## Что изменено
- Новый левый sidebar вместо нижней панели вкладок.
- Новый Dashboard с кассой, задолженностью, прибылью, активными договорами.
- Быстрые действия: договор, платеж, расход, движение денег.
- Блок платежей на сегодня и предупреждений.
- График платежей за последние 6 месяцев без сторонней библиотеки.
- Новый раздел «Клиенты» с группировкой договоров, остатком и просрочкой.
- Поиск теперь ищет также по телефону.
- Адаптивная навигация для телефона: sidebar превращается в выезжающее меню.
- Старые разделы и их функции сохранены: договоры, учет, движение денег, доход/расход, сегодня, предстоящие платежи, просрочка, партнеры, инвесторы, печать.
- Синхронизация Firebase сохранена.
- Экспорт/импорт базы и Undo/Redo сохранены.

## Важно про данные
В архиве нет локальной базы клиентов: рабочие данные продолжают храниться в Firebase и localStorage браузера. Замена `index.html` на GitHub Pages сама по себе не удаляет данные из Firebase.

## Автоматические напоминания
В текущей версии сохранены существующие WhatsApp-ссылки/напоминания. Полностью автоматическая отправка сообщений WhatsApp, когда сайт закрыт, требует внешнего сервиса/WhatsApp Business API и серверной части или автоматизации. Это сознательно не подключено в этой статической версии, чтобы не требовать от владельца API-ключи и аккаунты.

## Безопасность
Авторизация, роли пользователей и новые Firestore Security Rules в этой версии не внедрялись — это отложенный этап, как было согласовано.

## Установка
1. Распакуйте архив.
2. Замените старый `index.html` в репозитории этим файлом.
3. Закоммитьте и отправьте изменения в GitHub.
4. GitHub Pages продолжит использовать существующую конфигурацию Firebase из приложения.
